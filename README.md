# DevGotchi

A developer-themed virtual pet (Tamagotchi) game built with React and TypeScript.

Raise your own developer pet from an egg through junior, mid, senior, all the way to lead! Keep it fed, rested, and happy while leveling up its coding skills.

## Quick Start

```bash
npm install
npm run dev
```

## Tech Stack

- **React 18** with TypeScript
- **Vite 6** for build tooling
- **Vitest** for unit testing
- **ESLint + Prettier** for code quality

## Scripts

| Command              | Description                  |
|----------------------|------------------------------|
| `npm run dev`        | Start dev server on :3000    |
| `npm run build`      | Type-check & production build|
| `npm run test`       | Run tests once               |
| `npm run test:watch` | Run tests in watch mode      |
| `npm run lint`       | Lint source files            |
| `npm run format`     | Format with Prettier         |
